# 方程式 a(x − y) = bz のラド数 — 論文・プログラム・結果

Takumi Ichikawa の 2 本のプレプリント(査読なし)と、全てのプログラム、記録した結果です。

互いに素な正の整数 a, b について、ラド数 **R_k(a,b)** は「{1,…,n} を k 色でどう塗っても、`a(x − y) = bz` の解で
x, y, z が同じ色のもの(同じ数でもよい)が必ずある」ような最小の n です。

## 結果と状態

| 内容 | 状態 |
|---|---|
| R₂ = b²+b+1(1 < a < b) | 既知(Yao 2014)。一意性による新しい証明 |
| [1, b(b+1)] の良い 2 色の塗り方はただ 1 つ((2,3) を除く) | **証明**(論文 1 定理 1.1) |
| 全ての a < b で R₃ ≥ N(a,b) | **証明**(定理 1.2) |
| 全ての a ≥ 7 で R₃(a,a+1) = a³+5a²+8a | **証明**(計算つき。記号の SAT の証明を `cake_lpr` で検査) |
| 全ての k で R_k > b^k。D ≤ 1 または a+1 ≤ D ≤ 2a なら R_k ≥ L_k | **証明**(定理 1.4、4.5) |
| 予想 S ⇒ R₃ ≤ N | **証明**(定理 1.6) |
| 予想 S は「下の部分」(a の倍数の最初の max(ab+4a,4b) 個)から従う | **証明**(定理 7.6) |
| 下の部分(式 1 の領域、b ≤ 30、(2,3)・(2,5) を除く。この 2 つでは偽) | SAT ソルバーのみ(証明ファイルなし) |
| **予想 S そのもの** | **未解決** |
| b ≤ 60 の全ての組で R₃ = N(a,b)(R₃(2,3) = 61、R₃(2,5) = 181 を除く) | (2,3) 以外の 1041 組の上界を LRAT 証明で、`lrat-check` と `cake_lpr` で検査 |
| b ≤ 81 の全 1939 組で同じ | SAT ソルバーのみ(MiniSat) |
| R₄(3,4) = 461、R₄(5,4) = 741、R₄(6,5) = 1501 | 塗り方 + 分割探索、全ての葉の証明を `cake_lpr` で検査(論文 2) |
| R₄(3,5) ≥ 961、R₄(2,5) ≥ 951、R₄(4,5) ≥ 961、R₅(3,4) ≥ 1869、R₅(3(x−y)=2z) ≥ 399 | 具体的な塗り方を検査 |
| R₄(3,5) = 961 か | **未解決**(探索が終わらない) |
| k に対する増え方 | **未解決**(上界は Sanders 2026 の exp(k^{2+o(1)})) |

## 再現のしかた

必要なもの: 手順 0 は Python 3 と numpy(どの OS でも)、手順 5 は LaTeX。手順 1〜4 は **Linux**(Windows は WSL、Mac は Linux の仮想マシンなど)と、`bin_linux/README.md` のとおりソースから作った実行ファイル。
番号つきのスクリプトを順に実行します(Linux・Mac・WSL は `bash 0_check_lower_bounds.sh` など、Windows は同じ名前の `.bat`)。
全ての手順を、新しく展開したこのリポジトリで Ubuntu 24.04 で試しました(手順 2〜4 は小さい範囲だけ)。
どれも途中で止めても、もう一度実行すれば続きから進みます。

- `0_check_lower_bounds`: 両論文の下界の塗り方を全て、独立のプログラムで検査(数秒、`ALL GOOD` になるはず)
- `1_check_family_proof`: R₃(a,a+1) ≤ N(a ≥ 28)の LRAT 証明を `lrat-check` と `cake_lpr` で検査(約 1 分)
- `2_check_three_colour_proofs`: b ≤ 60 の 3 色の 1041 個の証明を作り直して検査(約 1 日。b = 57〜60 はヒープ 14 GB の `cake_lpr` が必要)
- `3_check_four_colour_proofs`: 461・741・1501 の分割の木の網羅と全ての葉の証明(数時間以上)
- `4_lemma_S_checks`: 予想 S の下の部分(始まりと各歩)、b ≤ 30(約 2 時間)
- `5_build_papers`: 2 本の PDF を作る

私の実行の記録は `results/recorded/` にあります。LRAT 証明そのものは大きいので入れていません(手順 1 のものだけ入っています)。

## 弱いところ(正直に)

1. 符号化(CNF)は、書く前に全ての節を方程式と別の手順で照合しています。
2. 色の対称性の破り方(first fit)は論文で議論していますが、機械では検査していません。
3. 分割の木の網羅は `tools/verify_subset.py` の別の手順で数えています(形式的ではありません)。
4. 予想 S の下の部分は SAT ソルバーの結果だけです。値の証明には使っていません。
5. 文献の調査は完全ではありません。Yao (2014) は要旨しか読めていません。
